# aim 使用教程

> **这是什么**：[aim](../README.md)（人物形象仓）的**操作手册**——
> 从 clone 到出片，每一步该敲什么、看到什么、缺东西会怎样。
>
> **给谁读**：要**用** aim 的人（不是要改 aim 的人）。
> 要改 aim 的读 [`AGENTS.md`](../AGENTS.md)；要定规格的读 [`specs/`](../specs/)。
>
> **一句话**：`aim` 把「这个人是谁」定成一份 JSON（契约），
> 再由脚本把它渲染成**这个人的**素材与片子。

---

## 〇、先认清三样东西

搞混这三样，后面的事全会拧巴：

| | 是什么 | 在哪 | 入库？ |
| --- | --- | --- | --- |
| **契约** | **这个人的事实**——他叫什么、长什么样、什么声音、什么人格、品牌片怎么打 | `models/<slug>/model.json` | **是** |
| **素材** | 参考图、生成的图、配乐、录音——**使用者的东西**（版权与口味是他们的） | `models/<slug>/assets/` | **否** |
| **产物** | 渲染出来的 PNG / MP4 / WAV | 上面两个目录里 | **否** |

**入库的是「它在哪」，不是「它本身」。**
换句话说：仓库里**只有事实和路径**，素材与成片都在使用者的机器上。

**缝是一个文件**：下游（别的程序）只**读** `model.json`，
**不 import 本仓的任何模块**。所以本仓改了什么，下游不受影响——
除非**契约的形状变了**（那要涨 `schema`，两边都得认，见 §六）。

## 一、五分钟跑通（先别改任何东西）

### 1. 装依赖

```bash
git clone https://github.com/growdu/aim.git
cd aim

# Linux 上**优先用系统包**——pip 编译 pycairo 要 cairo 的开发头文件
sudo apt-get install -y python3-cairo python3-numpy python3-pil \
                       python3-pytest python3-scipy
pip install fonttools            # 纯 Python，只用来读内置字体的 cmap
```

还差两个**系统级**的东西：

| 要什么 | 谁用 | 缺了会怎样 |
| --- | --- | --- |
| `ffmpeg` / `ffprobe` | 配音与成片 | 合成类脚本跑不了 |
| `mcode-tools` CLI + 生成额度 | `character generate` / `brand poses` / `brand backgrounds` | **生成类脚本跑不了**（其它命令不受影响） |

### 2. 装内置字体

```bash
./aim font install          # 装
./aim font install --check  # 查（会答「cairo 认得这个族吗」）
```

**字体不在，文字就画不出来**——本仓宁可报错也不画豆腐块。
跨机版式一致靠的就是这份内置字体子集（**入库**）。

### 3. 跑一遍体检

```bash
./aim doctor
```

输出是一张清单：**素材**（在不在）、**品牌片**（片头片尾、配乐窗口在不在）、
**形象规格**（眼镜、衣服色、铭牌字色定没定）、**背景 prompt** 定没定、
**底板配色** 定没定、**字体**在不在。

> **缺东西不是错误**——渲染会**降级**（少一块），`doctor` 单独报出来。
> 但**契约坏了才是硬错误**：`model.json` 读不了 → **报错退出**，不降级。

### 4. 看看命令表

```bash
./aim --help              # 全部命令
./aim character           # 这一组的动作
./aim character badge --help
```

`./aim` 是**门面**：命令表指向现有脚本，参数与退出码**原样转交**。
所以 `python3 scripts/brand/render_brand.py --intro` 也照样能跑——
**实现只有一份**。

## 二、从零建一个人

> **前提**：确认流程已经走完（音色定标 → 形象确认 → 人格确认 → 品牌片定稿），
> 结论在你手上——**在纸上、在别的工具里、或者直接改 JSON**。

### Step 1　写草稿

**草稿就是 `model.json` 本身**（还没归一化的那份）。
**只有你能写里面的事实**——脚本不发明身份。

最小的一份：

```json
{
  "person": "yourname",
  "identity": {
    "name": "你的名字",
    "role": "你的角色",
    "positioning": "一句话说清你是谁",
    "audience": "说给谁听",
    "taboos": ["不做泛泛而谈的科普"],
    "series": "系列名"
  },
  "voice": {
    "voice_id": "Chinese (Mandarin)_Radio_Host",
    "voice_name": "电台男主播",
    "pitch": -1,
    "speed": 1.33,
    "emotion": "neutral",
    "pronunciation": { "行锁": "航锁" }
  },
  "look": "3D 卡通小象幼崽，浅蓝灰色皮肤……",
  "persona": "一位冷静克制的工程师。\n- 冷静克制：不要夸张\n- 工程师：规整",
  "brand": {
    "name": "你的名字",
    "token": "yourname",
    "tagline": "一句话 slogan",
    "site": "your.site",
    "intro_line": "……{brand}……",
    "outro_line": "感谢观看。访问 {site}……",
    "colors": { "deep": "#2B4C7E", "light": "#D6E9FA" },
    "backgrounds": { "intro": "一段背景 prompt", "outro": "一段背景 prompt" }
  },
  "assets": {
    "source": "assets/character/source.jpg"
  }
}
```

**写不全没关系**：能空的字段留空，脚本会补空壳。
但**别瞎填**——空 = 「还没定」，填错 = 「定错了」。下游分不清这两者。

### Step 2　归一化成契约

```bash
./aim model build --person yourname --from /tmp/draft.json \
                  --out models/yourname/model.json
```

这一步做三件事：**补齐空壳** → **校验形状** → **校验通过才写**。

```bash
./aim model build --person yourname --check    # 只校验，不写
```

**它不发明身份值**——「站名叫什么」只能人写。
脚本发现草稿里的 `person` 跟命令行说的不是同一个人，会**拒绝写**
（那是拿错了文件，不是笔误）。

### Step 3　体检

```bash
export AIM_MODEL=models/yourname/model.json
./aim doctor
```

> **为什么设 `AIM_MODEL`**：脚本在 import 时就把模型读进模块里。
> 仓里有好几个人时，aim **报错列出候选，绝不猜**——
> 猜错就是拿别人的事实去生成这个人的素材与片子。
> 仓里只有一个人的时候，不设也能跑。

### Step 4　出形象

```bash
# 4.1 生成主形象 + 6 姿态表（**消耗生成额度**，要联网）
./aim character generate

# 4.2 戴眼镜（**没声明眼镜就整体跳过**——不是错误）
./aim character glasses

# 4.3 透明底合成白底版（合成，不重新生成）
./aim character white

# 4.4 盖铭牌（品牌词用**真实字体**写，不是模型画的）
./aim character badge

# 4.5 抹掉铭牌（平台判「过度营销」时用）
./aim character clear-badge
```

**一条命令跑完整条链**（从零建一个人时用这个）：

```bash
./aim assets build
```

它按依赖顺序跑上面那几步，产物留在 `models/<slug>/assets/`
（**不入库**——素材是使用者的）。细节见
[`本地素材回路.md`](本地素材回路.md)。
**已经有的耗额度产物会跳过**（生成要花钱）；要重做用 `--force`。

> **链上少了两步，这是有理由的**：
> 4.2 眼镜——`generate` 的 prompt 已经带眼镜（`look_spec.glasses` 声明了就带），
> `glasses` 是给**旧素材**补眼镜的另一条路，带人工关卡；
> 4.4 盖章——`generate` 生成后**自己就盖章了**，再盖一次是在已盖字的白块上盖第二次。

**抹完产出** `<slug>_character_2k_nobg_nobadge.png`——
在模型里它就是 `assets.mascot_plain`。
**盖铭牌写的是 `brand.token`**（品牌词），字色取 `look_spec.badge_text_color`。

产出在 `models/<slug>/assets/character/`：

```
<slug>_character_2k.png          主形象（白底）
<slug>_character_2k_nobg.png     透明底版（合成进视频用）
<slug>_pose_sheet.png            6 姿态设定表
```

**头像（`assets.avatar`）不在生成流程里**——它是你自己的素材，
放在约定位置、在 `model.json` 里声明位置就行。

**眼镜**：只在 `look_spec.glasses` 声明了才做。
没声明 = 这个人**不戴眼镜**，加眼镜流程**整体跳过**——
**不拿默认值糊过去**，因为糊过去下游就分不清「定错了」和「还没定」。

**想先看看要生成什么再决定花不花额度**：

```bash
./aim character generate --print-prompt
```

### Step 5　出品牌片

```bash
# 5.1 角色姿态（点赞 / 挥手）
./aim brand poses            # 两个都要
./aim brand poses --thumbsup # 只做点赞

# 5.2 AI 背景（两张，16:9）
./aim brand backgrounds
./aim brand backgrounds --intro   # 只做片头那张

# 5.3 成品音轨（按配乐窗口切曲混音）
./aim brand audio --library /path/to/music/library.json

# 5.4 渲染片头 / 片尾（2.833s，1920×1080）
./aim brand render
./aim brand render --intro        # 只渲片头

# 5.5 修底板里被 16:9 裁断的文字（真实字体重排）
./aim brand fix-plates
```

> ⚠️ **音轨在渲片之前**：渲片把音轨**烧进** mp4
> （`scripts/brand/render_brand.py`），音轨晚一步，渲出来是**静音片**，
> 而且得再渲一遍。`./aim assets build` 的顺序就是对的。

**一条命令跑完整条链**（Step 4 + Step 5 一起）：

```bash
./aim assets build
```

**`brand audio` 要三样**（缺一样就明说缺哪一样，不糊过去）：

| 要什么 | 从哪来 | 备注 |
| --- | --- | --- |
| **配乐台账** | `--library` 或 `AIV_MUSIC_LIBRARY` | 一份 JSON：`{"tracks":[{"id","local_path","sha256"}]}`。`local_path` 相对**台账所在目录的上上级**（曲库根） |
| **旁白** | `models/<slug>/assets/brand/audio/voice_intro.mp3` / `voice_outro.mp3` | **合成不在本仓**——用音色那侧的合成工具出，aim 只做**切窗口 + 混音** |
| **窗口** | `models/<slug>/brand_windows.json` | 见 Step 7 |

产出在 `models/<slug>/assets/brand/`：

```
clips/<slug>_intro_3s_1080p.mp4      片头
clips/<slug>_outro_3s_1080p.mp4      片尾
<slug>_pose_thumbsup_nobg.png         点赞姿态（透明底）
<slug>_pose_wave_nobg.png             挥手姿态（透明底）
bg_intro.png / bg_outro.png          两张背景
audio/intro_mix.wav / outro_mix.wav  成品音轨（旁白 + 配乐）
```

**两条硬规矩**（[`scripts/brand/readme.md`](../scripts/brand/readme.md) 有细账）：

1. **文字一律用真实字体在 cairo 阶段渲染**——模型生成的中英文会乱码。
2. **背景与形象分开生成**——AI 只画环境；角色用参考图生成，
   铭牌由代码盖章，文字与版式由代码确定。

**背景 prompt 没定 = 生成脚本拒绝出货**（不糊过去）。
配 prompt 的时候记得写清**哪一侧将来要压白放字**——
片头右侧、片尾靠地平线那一侧。

### Step 6　定音色

```bash
# 6.1 量参照录音（--chars 是对应的口播稿字数）
./aim voice measure --path ref.wav --chars 42

# 6.2 有候选稿就与参照稿逐项比（多了差值与排序分）
./aim voice measure --path cand.wav --chars 42 --ref ref.wav --ref-chars 42

# 6.3 查多音字读音（会合成探针，**要联网**）
./aim voice check --word 行锁
./aim voice check --audio cand.wav --from 0 --to 3   # 离线，用已有音频
```

**多音字是这套音色最容易翻车的地方**——
比如这把音色会把词首的「行」念成 xíng。
解法是**替换规则**（`voice.pronunciation`），不是换音色。
**换稿必须重新定标**：稿子变了，之前的量测就不作数了。

判据与量测的细节见 [`scripts/voice/readme.md`](../scripts/voice/readme.md)。

### Step 7　配乐窗口

```bash
# 窗口决策由配乐台账那侧产出（`bgm windows` 挑一对）
# aim 只**读**它：models/<slug>/brand_windows.json
```

```json
{
  "version": 1,
  "duration_s": 2.833,
  "intro_start_s": 8.733,
  "outro_start_s": 5.9,
  "track_id": "series-motif-01",
  "track_sha256": "994ef3ac…"
}
```

**规则只有一条**：`outro_start + duration == intro_start`——
片尾结束时正好落在片头的起音点上，两段拼起来是同一段连续音乐。

**决策入库，音频不入库。** 换曲子重挑一次写回这个文件，脚本不用改。
`brand audio` 会拿台账里的 `sha256` **核对曲子的指纹**——对不上会拒绝混
（曲子换过了，窗口就该重挑）。

### Step 8　交付给下游

下游**只读** `models/<slug>/model.json` 与它指到的素材：

```json
{
  "brand": {
    "clips": { "intro": "assets/brand/clips/…_intro_3s_1080p.mp4" },
    "audio": { "intro": "assets/brand/audio/intro_mix.wav" }
  }
}
```

**相对路径按 `model.json` 所在目录解析**（= `models/<slug>/`）——
下游**不需要知道本仓根在哪**。

**下游怎么挑片**：先看模型指明的那张；没有就在 `clips/` 目录里按名字找
（含 `intro` / `outro`），取**最短**的那张（规格 ≤ 3 秒）。

## 三、命令速查

全部 15 条。**参数原样转交**给脚本，**退出码原样传回**。

| 命令 | 干什么 | 常用参数 |
| --- | --- | --- |
| `aim doctor` | 体检：契约与素材齐不齐（**只报告，不改**） | `[model]` 体检哪一份 |
| `aim model build` | 归一化成 `model.json`（**校验通过才写**） | `--person` `--out` `--from` `--check` |
| `aim font install` | 装内置字体子集 | `--check` 只看状态 |
| `aim character generate` | 生成主形象 + 6 姿态表 | `--print-prompt` 不生成只打 prompt |
| `aim character glasses` | 戴眼镜（没声明就整体跳过） | `--batch` `--only` `--promote` `--resume` `--no-stamp` |
| `aim character badge` | 盖铭牌（真实字体写品牌词） | `[paths…]` 缺省 = 素材目录里那几张 |
| `aim character clear-badge` | 抹掉铭牌 | `[paths…]` |
| `aim character white` | 透明底铺成白底 | `[source] [output]` |
| `aim brand poses` | 点赞 / 挥手姿态素材 | `--thumbsup` `--wave` |
| `aim brand backgrounds` | 两张 AI 背景（含语义验收） | `--intro` `--outro` |
| `aim brand render` | 渲染片头 / 片尾 | `--intro` `--outro` |
| `aim brand fix-plates` | 修底板被裁断的文字 | — |
| `aim brand audio` | 按窗口切曲混音，出成品音轨 | `--library` 配乐台账 |
| `aim voice measure` | 量参照录音的音色特征 | `--path` `--chars` `--ref` `--ref-chars` `--json` |
| `aim voice check` | 查多音字读音 | `--word` `--samples` `--audio` `--from` `--to` `--calibrate` |

**每条都有 `--help`**——那是**交付形式的一部分**：
交付的是命令行，就得能问。

## 四、换一个人（不碰代码）

**换人只改模型，不改代码。** 换人时依次看这几处：

| 要改的 | 在哪 | 注意 |
| --- | --- | --- |
| 身份、定位、受众、禁忌 | `identity` | **空 = 还没定**，别编 |
| 音色参数、多音字 | `voice` | 换音色要**重新定标** |
| 长相描述 | `look` | 一整段话，不是关键词数组 |
| 眼镜、衣服色、铭牌字色、耳麦 | `look_spec` | **不戴眼镜就别声明** |
| 人格 | `persona` | **一整段**文字 |
| 站名、slogan、文案、配色、背景 prompt | `brand` | 底板配色在 `brand.colors` |
| 素材位置 | `assets` | 相对 `model.json` 所在目录 |

**代码里不许写死任何一个人**——人格、音色、形象、站名、配色、
背景 prompt 全在模型里。有测试盯着这一点（见 §七）。

## 五、排错

| 症状 | 原因 | 怎么办 |
| --- | --- | --- |
| `仓里有好几个人，不猜用哪个` | 仓里有多个 `model.json` | `export AIM_MODEL=models/<slug>/model.json` |
| `schema 是 N，比本仓认识的 M 新` | 契约形状比本仓新 | 升级本仓；**再看一眼还有谁在读这份契约**（下游那份读取器也得涨） |
| `缺少形象原型参考图` | `assets.source` 没写或文件不在 | 写上路径，或留空——留空就不跑生成流程，直接用 `assets.mascot` |
| `命令不存在：mcode-tools` | 生成类脚本要 mcode-tools CLI | 装它（其余命令不受影响） |
| `字体族 … 没装` | 内置字体没装 | `./aim font install` |
| `窗口不相接` | 配乐窗口对不上 | 重挑一对窗口，写回 `brand_windows.json` |
| `没指到配乐台账` | `brand audio` 找不到曲库 | `--library` 或 `AIV_MUSIC_LIBRARY` 指一份 |
| `缺少素材：voice_intro.mp3` | 旁白没合成 | 旁白**合成不在本仓**——用音色那侧的工具出 |
| `指纹与台账不符` | 曲子换过了，窗口作废 | 重挑窗口（`bgm windows`） |
| `背景 prompt 还没定（生成脚本会拒绝出货）` | `brand.backgrounds` 是空的 | 写 prompt——**这是事实，只能人写** |
| `这个人（模型目录名）不匹配` | 草稿里的 `person` 与命令行说的不是同一个人 | 改对——**别静默改名**，那是拿别人的事实写进这个人的名下 |
| 缺字 / 豆腐块 | 字体没装或字体缺字 | 装字体；字体子集覆盖 GB 2312-80 全集 |

## 六、契约变了怎么办

**`model.json` 的形状变了**（加了一个段、改了一个字段）：

1. **涨 `schema`**——`aimkit/model.py` 里的 `SCHEMA_VERSION`。
   读不懂新形状就**报错退出**，不静默忽略。
2. **先数一遍还有谁在读这份契约**——缝是文件，**每一端各有一份读取器**。
   本仓涨了，**下游那份读取器不跟着涨**，下游读到的就是「比它认识的旧」
   → 下游**报错退出**（那是对的），但**得有人去改那一端**。
   报错信息落在下游，根因在上游这一头。
3. 更新 [`specs/平台契约.md`](../specs/平台契约.md)。

## 七、确认没搞坏

```bash
cd aim
python3 -m pytest tests/ -q
```

**全套只有一条**——本仓小，模块之间共用同一份 `model.json`，拆开跑没意义。

生成素材要联网、要额度）。

## 八、让 AI 协作者来干

aim 另有一份**分发包**（**不在本仓**——本仓是跑东西的仓，
不是 Claude Code 的配置仓）：**skill + agent**，装完就能用。

```bash
git clone https://github.com/growdu/aim-dist.git && cd aim-dist
./install.sh                       # 装到 ~/.claude
./install.sh --aim-home /path/aim  # aim 仓不在旁边就指一份
./install.sh --uninstall           # 卸掉
```

- **skill**：教 agent 怎么用 aim——流程、12 条铁律、命令表。
- **agent**：专职代理——改契约、跑渲染、查素材。

两者都调**同一个 `./aim`**——**实现只有一份**。
铁律与流程**指的是本仓这份**（`AGENTS.md` / `specs/`），不是抄一份；
命令表在**安装时从本仓现生成**，单一出处，不会过期。
