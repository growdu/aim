# 品牌片规范

> **结构是规则，具体的图与文案是例子**：文案在 `model.json` 的 `brand` 段里。

---

## 一、结构

定稿的两支品牌片在 `models/<slug>/assets/brand/`（见 [音色规范](音色规范.md) 与
`scripts/brand/readme.md`）。

| | 片头 | 片尾 |
| --- | --- | --- |
| 时长 | 2.833s（68 帧 @ 24fps） | 2.833s（68 帧 @ 24fps） |
| 形象 | 你的形象 · 点赞姿态（戴深藏蓝方框眼镜） | 你的形象 · 挥手姿态（戴深藏蓝方框眼镜） |
| 文案槽位 | 口号 / 副标题 / 胶囊 | 感谢 / 副标题 / 三胶囊 |
| 旁白 | 一句欢迎 | 一句「下次见」 |

---

## 二、文案（取值在 `model.json` 的 `brand` 段）

*示例*（文案取值见 `model.json` 的 `brand`）：

| | 片头 | 片尾 |
| --- | --- | --- |
| 文字 | `<站名>` / `<片头标语>` / 胶囊「<片头副标题>」 | `感谢观看` / `<片尾副标题>` / 三胶囊「`<站点地址>`」「订阅关注」「点赞支持」 |
| 旁白 | 欢迎来到 `<品牌词>`，`<标语>`。 | `<片尾旁白>` |

`brand` 段里与品牌片有关的键：

| 键 | 管什么 |
| --- | --- |
| `name` | 落版与片尾字幕上的名字 |
| `token` | 画面里出现它就算品牌标识（也是铭牌上的字） |
| `tagline` | 片头副标题 |
| `site` | 片尾落版（通常是站点地址） |
| `intro_tagline` | 片头标语 |
| `intro_line` | 片头旁白与胶囊整句（`{brand}` / `{site}` 会被替换） |
| `outro_line` | 片尾落版整句（`{brand}` / `{site}` 会被替换） |
| `outro_narration` | 片尾旁白 |
| `outro_subtitle` | 片尾副标题 |
| `outro_title` | 片尾落版的大字 |
| `outro_labels` | 片尾落版的两条胶囊标签 |
| `share_suffix` | 片头药丸那句话的后缀（自带「· 」） |
| `share_emphasis` | 药丸里拆成两段画的那个大字 |
| `clips` | 品牌片 mp4 的位置（`intro` / `outro`） |
| `audio` | 成品音轨的位置（`intro` / `outro`） |
| `windows` | 配乐窗口决策（`brand_windows.json`，跟着这个人） |
| `backgrounds` | 两张背景的**生成 prompt**（`intro` / `outro`）——空 = 还没定 |
| `colors` | 底板的**配色**（`deep` 深色 / `light` 浅色，`#RRGGBB`）——空 = 还没定 |

这些常量在 `scripts/brand/render_brand.py` 里从模型读，不写死。

**配色也是这个人的事实。** 底板上压字的深色与浅色原来写死在渲染脚本里
（两行三元组），换个人——片子还是上一个人的配色，而画面照常生成、
时长照常对，没有任何报错。现在它在 `brand.colors` 里：
**换人只改模型，不改代码。** 没声明就退回框架的中性色（墨色 / 白）。

---

## 三、技术路线

**AI 只出背景底板，形象与文字全部由代码合成。**

- 文字一律用**真实字体**在 cairo 阶段渲染——模型生成的中英文会乱码；
- 字体族名由 `aimkit/fonts.py` 解析（首选仓里那份字体子集）；
- 渲染出的 mp4 在 `models/<slug>/assets/brand/clips/`。

细节见 `scripts/brand/readme.md`。
